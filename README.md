# 工控PLC & 电气工程师 企业面试刷题宝典 (Web版)

> 本系统根据 `模拟面试题库-答案编辑.xlsx` 全量 **547 道企业面试真题** 构建，完全单文件独立封装，**无需网络连接，不依赖任何第三方 CDN 或后端服务**，双击即可在任何浏览器（Chrome、Edge、微信、手机端、平板等）中流畅使用。

---

## 🚀 快速启动

1. **直接双击打开**：
   在文件夹中直接双击 [`index.html`](file:///e:/PLC/a/011.企业面试/index.html)，系统会自动在默认浏览器中打开。

## 🎯 五大核心功能模块

### 1. 🗂️ 沉浸式卡片刷题模式 (Flashcard Mode)
- **逐题研读与自测**：默认展示题目与口语化提问方式（“面试官可能会这样问……”），点击 **查看参考答案**（或按键盘 **空格键**）翻转卡片。
- **三段式工业标准回答架构**：
  - 💡 **原理与现场理解 (What)**：核心考点与原理大白话解释。
  - 🛠️ **标准操作与实战步骤 (How)**：规范的现场操作与回答逻辑。
  - ⚠️ **现场避坑与易错禁忌 (Traps & Mistakes)**：高频扣分点与现场安全雷区。
  - ⭐ **专属实战解答**：导师现场经验与高频反馈。
- **做题自评**：
  - `❌ 没答上来`（按数字键 `1`）👉 **自动加入错题本**，待后续重点突破。
  - `⚠️ 模棱两可`（按数字键 `2`）👉 加入复习队列。
  - `✅ 熟练掌握`（按数字键 `3`）👉 计入掌握进度。
- **个人笔记**：每道题均支持输入专属笔记，输入即自动保存。
- **语音朗读 (🔊)**：点击朗读按钮或按快捷键 `V`，支持中文语音播报题目。

### 2. 📖 背题总览与全真检索 (Browse & Search)
- **毫秒级即时检索**：支持对题号、题目、口语提问、考点提纲、易错点进行全文高亮匹配。
- **24大分类导航横滑栏**：安全与测量、低压元器件、继电控制、选型与柜体、1200博途、200SMART、变频伺服、企业专项等全部分类一键切换。
- **多维度筛选**：按难度（Easy/Mid/Hard）、标签（speech口述题/interview核心题）、学习状态（已掌握/需复习/错题本/收藏夹）精准筛选。
- **全局操作**：支持一键展开所有答案、一键折叠答案。

### 3. ⏱️ 企业技术面全真模拟 (Mock Interview)
- **6套专业面试题组**：
  1. 🌟 **综合全能面试** (15题，涵盖电气基础、PLC、变频伺服、调试、企业专项)
  2. 💻 **西门子PLC专项** (10题，S7-1200/1500、SMART、通信、逻辑结构)
  3. ⚡ **电气控制与配电** (10题，低压元器件、继电回路、安全测量、图纸)
  4. 🔧 **现场排故与企业实战** (10题，企业专项高频题、突发故障处理)
  5. 🎲 **5题速答随身测** (5题全随机)
  6. 📕 **错题攻坚突击** (专抽错题本中的薄弱点)
- **倒计时限制**：支持每题 3分钟、2分钟或无限制。
- **在线答辩草稿板**：边答边打字列提纲。
- **全方位面试报告**：自动计算得分与评级（王者/优秀/良好/需加强），支持**一键将本次失分题目打入错题本**。

### 4. 📕 错题攻坚与重点收藏 (Mistakes & Bookmarks)
- 汇总所有未掌握或含糊不清的题目，提供“一键开启错题刷题卡”。
- 掌握后可点击“消灭此题”，自动从错题本清除并计入“消灭错题成就”。

### 5. 📊 进度看板与数据备份 (Stats & Backup)
- **掌握度圆环图表**：实时展示总体掌握度百分比。
- **24大分类掌握度看板**：直观展示每一个模块的学习进度条。
- **数据永久保存**：本地浏览器 LocalStorage 自动记录；支持**导出备份文件（JSON）**与**导入恢复**。

## ⚡ 刷题快捷键清单

| 快捷键 | 功能说明 |
| :--- | :--- |
| **空格 Space** | 展开 / 收起参考答案 |
| **→** 或 **PageDown** | 下一题 |
| **←** 或 **PageUp** | 上一题 |
| **1** | 标记为「❌ 没答上来」（加入错题本） |
| **2** | 标记为「⚠️ 需复习」 |
| **3** | 标记为「✅ 熟练掌握」 |
| **S** | 收藏 / 取消收藏本题（⭐） |
| **R** | 随机抽取下一题 |
| **V** | 语音朗读题目与提纲 |

## 🔄 Excel 题库更新与重新生成

如果您后续在 Excel 表格 `模拟面试题库-答案编辑.xlsx` 中新增了题目或修改了答案，只需运行构建脚本即可重新生成最新的网页：

```bash
python build_website.py
```

终端将重新读取 Excel 数据并输出最新的 `index.html`。
